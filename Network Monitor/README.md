# OMG Network Monitor

一个不依赖浏览器和额外运行时的原生 Windows 网络监控器。

## 功能

- 监控全系统 IPv4/IPv6 TCP 和 UDP 端点，映射到进程、PID 和可执行文件路径。
- 记录连接新建/关闭、协议、本地与远端端点、TCP 状态、首次和最后发现时间。
- 监控所有活动网卡的累计上传/下载与实时速度，保留 120 秒曲线。
- JSONL 事件日志与 CSV 快照导出；日志默认保存 30 天。
- 搜索进程、PID、IP、端口和连接状态；可暂停界面采样。
- 默认注册当前用户的 Windows 开机启动，关闭主窗口后驻留系统托盘。

“建议复核”是低噪声提示：命中常见远控/后门端口，或一个无法读取进程路径的进程建立了对外 TCP 连接。它不是恶意判定；双击对应行可复制完整详情以便进一步排查。

## 构建和运行

在 PowerShell 中运行：

```powershell
& '.\build.ps1'
& '.\Network Monitor.exe'
```

构建脚本会优先使用 PATH 中的 `g++`，并兼容本仓库已有的 MinGW-w64 工具链。

## 配置

编辑 `network-monitor.yaml`，然后在程序中点击“重载配置”。`start_with_windows: false` 会删除开机启动项。日志目录位于：

```text
%LOCALAPPDATA%\OMG Network Monitor\logs
```

## 能力边界

Windows 的系统连接表能可靠提供全系统端点与所属进程，网卡计数器能提供总体字节量；但它们不会提供每个进程的精确字节量。HTTPS/TLS、QUIC 等流量的内容是加密的，本工具不会安装根证书、网络驱动或执行中间人解密。因此它能回答“哪个进程在何时连接了哪里、系统传了多少数据”，不能直接读取加密上传的文件内容。UDP 表只暴露本地端点，未连接 UDP 的每个远端目的地需要驱动或 ETW 包级捕获才能获得。

普通用户权限即可运行；以管理员身份运行时，某些受保护进程的路径识别率可能更高。
