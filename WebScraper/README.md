# OI Rank Scraper

Tkinter GUI scraper for `http://123.60.188.246/oi-rank`.

## Run

Double-click `run.bat`, or run:

```powershell
python .\oi_rank_scraper.py
```

If Python is not installed, `run.bat` opens the browser GUI in `index.html`.

## Controls

- Click the green `刷新` button to reload.
- Press `Ctrl+R` or `F5` to reload.
- The app loads on startup and refreshes every 10 minutes.
